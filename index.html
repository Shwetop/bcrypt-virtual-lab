Aim & Learning Objectives

Aim

To understand, implement, and analyze the Bcrypt adaptive password hashing algorithm. This includes evaluating the function of cryptographic salts, parsing modular hash string components, demonstrating non-deterministic hash outputs for identical passwords, and analyzing key stretching mechanisms.

Learning Objectives

  • Differentiate between one-way hashing and two-way encryption.
  • Explain why fast hash algorithms (MD5, SHA-256) are vulnerable to GPU rainbow table attacks.
  • Parse the standard Bcrypt format: $identifier$cost$salt+hash.
  • Demonstrate how random salts prevent pre-computed dictionary attacks.
  • Identify the 72-byte password length limitation inherent to Eksblowfish.
