Step-by-Step Lab Procedure

Follow these sequential steps to conduct your virtual laboratory experiment.

1

Password Hashing Experiment

Navigate to the Experiment Page. Enter any passphrase in the Hash Generator. Select a cost factor (e.g. 10). Click Generate Bcrypt Hash to observe random salt generation, execution time in milliseconds, and the resulting 60-character string.

2

Password Verification Check

Use the Password Match Verifier on the Experiment page. Input a candidate password and paste a target Bcrypt hash. Click Verify Password Match to test verification outcomes.

3

Salt Randomness Verification

Use the Random Salt Demo on the Experiment page to hash the exact same password 3 times consecutively. Observe that each run generates a unique hash string. Run the verification check to prove that all 3 distinct hashes successfully match the original password.

4

Modular Format Parsing

Inspect the generated string using the interactive Hash Breakdown Tool on the Experiment page. Hover or click on each segment to isolate the Version Identifier ($2b$), Cost Factor, 128-bit Salt, and 192-bit Hash Digest.

5

Pipeline Visualization & Self-Assessment

Step through the Pipeline Visualizer to see internal Eksblowfish stages, then complete the Self-Assessment Quiz to evaluate your understanding.
