Step 1: Input Pre-processing & 72-Byte Validation

Password Preparation & Length Checking

The plaintext password is converted to a UTF-8 byte array. If length exceeds 72 bytes, characters beyond index 71 are discarded due to Blowfish key schedule constraints.

Sample Input: "CyberLabSecurity2026!#Pass" (26 Bytes) → Accepted without truncation
Step 2: Cryptographic CSPRNG Salt Generation

Generating 128-bit Random Salt

A Cryptographically Secure Pseudorandom Number Generator (CSPRNG) generates 16 raw bytes (128 bits) of unique random data to inject entropy into key expansion.

Generated Raw Salt (16 Bytes Hex): 0x7F 0x3A 0x9B 0x11 0x4E 0xC8 0xD2 0x0F 0x88 0x31 0xA4 0x7E 0x90 0x12 0x55 0xBC
Step 3: Eksblowfish Key Expansion

Expensive Key Schedule (Key Stretching)

The password and salt are iteratively fed into Eksblowfish state initialization. The algorithm loops 2Cost Factor times (e.g. 210 = 1,024 rounds), repeatedly interweaving salt and password into the Blowfish P-array and S-boxes.

Step 4: Ciphertext Generation (OrpheanBeholderScryDoubt)

64 Blowfish Encryption Rounds

Using the expanded key state, the constant 192-bit string "OrpheanBeholderScryDoubt" is encrypted 64 times in Electronic Codebook (ECB) mode to generate the 24-byte hash digest.

Target Text: "OrpheanBeholderScryDoubt" → Encrypted to 24 raw bytes
Step 5: Radix-64 Encoding & Formatting

Final Modular String Assembly

The 16-byte salt (22 Radix-64 chars) and 24-byte digest (31 Radix-64 chars) are concatenated with prefix $2b$ and cost factor 10$ to produce the final 60-character string.
